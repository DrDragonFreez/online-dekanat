О сервисе

        

          «Деканыч» — цифровой секретарь деканата. Читает студенческие документы,
          извлекает поля, проверяет их по Положению и отвечает на вопросы со ссылками на пункты.
        

      


      

        

          
📄

          
OCR + выравнивание

          

            Tesseract распознаёт текст, автовыравнивание компенсирует наклон скана.
            Для PDF используется текстовый слой, для фото — OCR с поворотом на 90/180/270.
          

        


        

          
🧩

          
Извлечение полей

          

            Сначала поля ищутся по меткам «Метка: значение». Если что-то не нашлось —
            подключается LLM (Qwen2.5), и она добирает пропущенное.
          

        


        

          
✍️

          
Подпись и печать

          

            Проверка графических отметок через HSV-маску и морфологию.
            Для синтетических документов — strict-режим, для реальных фото — loose.
          

        


        

          
📘

          
Сверка с Положением

          

            Правила проверки описаны в data/doc_types.yaml.
            Каждый ответ сопровождается ссылкой на пункт — rule:X.Y.
          

        


        

          
➕

          
Новый тип без кода

          

            Новый тип документа добавляется правкой одного YAML-файла:
            анкоры, поля, метки, паттерны, пороги, правила проверки и LLM-примеры.
            В коде — ноль изменений.
          

        


        

          
🎯

          
Ссылки на источники

          

            Каждый ответ содержит источники: field:student_name для полей,
            rule:3.1 для пунктов Положения. Если ответа нет — сервис честно скажет.
          

        

      


      

        
Версия 1.0

        
Все данные в примерах вымышлены. Документы не имеют юридической силы.
